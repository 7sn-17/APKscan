# 🛡️ APKscan

موقع لفحص تطبيقات أندرويد (APK / XAPK) قبل تثبيتها.

## المميزات
- ✅ فحص الصلاحيات
- ✅ كشف الأنماط المشبوهة
- ✅ تحليل URLs
- ✅ كشف المكتبات الأصلية
- ✅ دعم XAPK كامل
- ✅ تقرير احترافي بالعربي

## طريقة الاستخدام
1. افتح الموقع
2. ارفع ملف APK أو XAPK
3. انتظر الفحص
4. اقرأ التقرير
